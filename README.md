# Create Checklist to JEI

将 Create 机械动力的炮塔材料清单转换为 JEI 原生书签，方便在建造过程中查看和整理待收集材料。

> **版本：** 0.1.3  
> **运行侧：** 仅客户端  
> **项目状态：** 测试版

## 功能

- 自动识别玩家物品栏中的 Create 炮塔打印材料清单，包括只读书写的剪贴板和由炮塔生成的材料清单。
- 按物品显示材料清单中剩余数量及已完成状态，并支持在多个清单之间切换和分页浏览。
- 默认选中清单中的缺少项；可调整选择后，将所选材料添加到 JEI 原生书签。
- 已存在的 JEI 书签会自动跳过；导入的物品悬停在 JEI 书签上时，可查看对应清单中的缺少数量。
- 按 **K** 随时打开清单助手；检测到未完成清单时也会自动提示。
- 不会修改玩家物品或清单内容；添加书签时由 JEI 自身负责更新和保存书签数据。

## 兼容性

| 组件 | 要求 |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.233 或更高版本（同一兼容系列） |
| Create | 6.0.10 至 6.0.x |
| JEI | 19.38.0.366 至 19.38.x |
| Java（构建） | JDK 21 |

运行时需要在**客户端**安装兼容版本的 Create、JEI 和本模组。本模组不需要安装在专用服务器上。

> JEI 书签写入使用了针对 JEI 19.38 内部实现的反射适配，并非稳定的公开 API。后续 JEI 版本可能改变相关结构；请使用上表所列版本范围。

## 安装

1. 确认实例使用上表所列的 Minecraft、NeoForge、Create 和 JEI 版本。
2. 将 `createcheckjei-0.1.3.jar` 放入该实例的 `mods` 文件夹。
3. 启动游戏。建议在首次使用前备份实例的 `config/jei` 文件夹。

如果你从源码构建，请使用 `build/libs/createcheckjei-0.1.3.jar`。安装新版本前，请移除该模组的旧版 JAR，避免重复加载。

## 使用

1. 将炮塔打印的材料清单放在玩家物品栏中。
2. 按 **K** 打开清单助手；如果检测到尚有缺少材料的清单，助手也会自动弹出。
3. 使用左右箭头切换清单，使用页码按钮或鼠标滚轮翻页。
4. 选择需要导入的缺少项，然后选择 **确认添加至 JEI**。已完成的项目不会导入，重复书签会自动跳过。
5. 将鼠标悬停在 JEI 书签上，可查看导入时记录的清单缺少数量。

按键可在 Minecraft 的 **选项 → 控制 → 按键绑定** 中重新设置。按 K 手动打开时，即使没有找到清单，也会显示助手窗口并提示未检测到清单。

## 从源码构建

项目使用 Gradle 8.10.2 和 JDK 21。Windows 用户可在项目根目录运行：

```powershell
.\build_windows.bat
```

构建脚本会查找 JDK 21；若本机尚未安装 Gradle 8.10.2，则会下载所需 Gradle 发行版。也可以通过 `JAVA21_HOME` 环境变量指定 JDK 21 安装目录。构建产物位于 `build/libs/`。

## 故障排查

- **按键没有反应：** 检查按键绑定，并确认本模组已在客户端加载。
- **没有识别到清单：** 确认物品是 Create 炮塔生成的打印清单，并放在玩家物品栏中；普通书本和其他剪贴板不会被识别。
- **无法添加 JEI 书签：** 检查 JEI 版本是否在兼容范围内。若内部结构无法访问，游戏日志会输出 `CreateChecklistJEI/Bookmarks` 相关错误；请同时提供 `logs/latest.log` 以便排查。
- **清单识别或数量不正确：** 请提供清单物品截图、使用的模组版本以及 `logs/latest.log` 中相关信息。
